# Sons de notification EasyCRM

## Fichier de son pour les appels

Placez un fichier `phone-ring.mp3` dans ce dossier pour entendre un son lors des notifications d'appel.

Le fichier doit être au format MP3 et d'une durée raisonnable (2-5 secondes recommandées).

## Exemple de sources de sons libres :
- https://freesound.org/
- https://pixabay.com/sound-effects/
- https://zapsplat.com/ (inscription requise)

## Format recommandé :
- Format : MP3
- Durée : 2-5 secondes
- Qualité : 128 kbps
- Volume : modéré (le volume sera automatiquement réduit à 50%)
